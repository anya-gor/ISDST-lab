# Чек-лист ретроспективы (формат Start / Stop / Continue)

- [ ] Выполнена ли Sprint Goal? Сколько SP ушло на Expedite (доля от ёмкости)?
- [ ] Карточки с Wait ≥ 3 дня: где стояли и почему?
- [ ] Сколько раз нарушался WIP-лимит? Кто и почему?
- [ ] Были ли баги, которые вернулись? Есть ли регрессионные тесты?
- [ ] Парное программирование: где помогло / где мешало?
- [ ] Действия: максимум 2 улучшения, у каждого владелец и срок.
