# Промпты

Инструмент: Claude Code (Claude Sonnet). Промпты записаны коротко, но по ним можно повторить работу. Личных данных и секретов в промптах не было.

**1.** "Реализуй расчёт стоимости поездки самоката: старт 50 руб. + 8 руб. за минуту, минуты округляются вверх. Python, без библиотек."

Получился черновик с `round(seconds / 60)` и числами прямо в коде. Округление неправильное, так оставлять нельзя.

**2.** "Напиши тесты на pytest: 0 минут, длинная поездка, округление, отрицательное время. Ожидаемые значения бери из условия, а не из своего кода."

7 тестов, на черновике 4 из них упали. Хорошо, что тесты сразу показали ошибку.

**3.** "Исправь округление вверх без float и добавь проверку на отрицательное время."

Стало `-(-s // 60)` и `ValueError`. Все 7 тестов прошли.

**4.** "Сделай ревью billing.py: магические числа, хранение денег, граничные случаи, проверка входных данных. Для каждой находки скажи, насколько это серьёзно, и что предлагаешь."

9 замечаний, они разобраны в `docs/ai-review.md`. Одно (ограничение на 24 часа) не принято.

**5.** "Вынеси тариф в конфиг (dataclass и переменные окружения), деньги считай в Decimal, добавь тесты на nan, inf, bool, строки и отрицательный тариф."

Получился текущий `billing.py` и 30 тестов. Граничные значения 59, 60, 61 секунда проверены руками.

## Выводы по работе с ИИ

Плюсы: быстро пишет каркас, подсказывает граничные случаи, о которых легко забыть, экономит время на однотипных тестах.

Минусы: первый вариант кода выглядел правильным, но был с ошибкой. Иногда предлагает лишнее (ограничение на длину поездки). Если не сказать явно, может написать тесты, которые подстроены под его же код, и тогда они ничего не проверяют.
